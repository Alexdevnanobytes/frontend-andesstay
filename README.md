# frontend-andesstay

Angular + MSAL. Configura `src/environments/environment.ts` con los Client ID de frontend y API, tenant, scope y Redirect URI. Arranca con `npm ci && npm start` y abre `http://localhost:4200/`. El proxy local entrega `/api` a `localhost:8080`. Para producción cambia `apiBase` a la URL del API Gateway y compila con `npm run build`. Instrucciones completas en el README del paquete AndesStay.
